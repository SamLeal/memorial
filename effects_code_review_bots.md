## Fichamento do Artigo: "Effects of Adopting Code Review Bots on Pull Requests to OSS Projects"

### Referência

WESSEL, Mairieli et al. Effects of adopting code review bots on pull requests to OSS projects. In: 2020 IEEE international conference on software maintenance and evolution (ICSME). IEEE, 2020. p. 1-11.

### 1. Fichamento de Conteúdo

O artigo investiga como a adoção de bots de revisão de código afeta a dinâmica de pull requests em projetos de Software de Código Aberto (OSS). Utilizando um desenho de regressão descontínua, os autores analisaram 1.194 projetos hospedados no GitHub. Os resultados indicam que, após a adoção de bots de revisão de código, houve um aumento no número de pull requests mescladas(merge) mensalmente e uma diminuição nas pull requests não mescladas. Além disso, observou-se uma redução na comunicação entre desenvolvedores. Esses resultados sugerem que bots de revisão de código podem melhorar a eficiência do processo de integração de código, mesmo que como consequencia possam reduzir as interações humanas durante as revisões.

### 2. Fichamento Bibliográfico

- **Bots de Revisão de Código:** Ferramentas automatizadas que auxiliam na revisão de código, interagindo nos mesmos canais de comunicação que os desenvolvedores humanos. 
- **Linters:** Ferramentas que analisam o código-fonte para identificar erros de programação, violações de estilo e possíveis bugs.
- **Desenho de Regressão Descontínua (RDD):** Método estatístico utilizado para identificar efeitos causais de uma intervenção em dados observacionais.
