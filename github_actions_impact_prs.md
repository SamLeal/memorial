## Fichamento do Artigo: GitHub Actions: The Impact on the Pull Request Process

### Referência

WESSEL, Mairieli et al. Github actions: the impact on the pull request process. Empirical Software Engineering, v. 28, n. 6, p. 131, 2023.

### 1. Fichamento de Conteúdo

O artigo investiga como os desenvolvedores de software utilizam o GitHub Actions para automatizar seus fluxos de trabalho, as discussões em torno dessa ferramenta e os efeitos de sua adoção na dinâmica das pull requests (PRs). Foram analisados dados de 5.000 repositórios ativos no GitHub, dos quais aproximadamente 30% adotaram o GitHub Actions, utilizando 973 ações predefinidas diferentes. Discussões em fóruns e no Discord revelaram que muitos desenvolvedores buscam ajuda na implementação dessas ações, indicando desafios na depuração e contribuição. A adoção do GitHub Actions resultou em mudanças na dinâmica das PRs: para PRs aceitas, houve redução no número de PRs e commits, mas aumento nos comentários; para PRs rejeitadas, observou-se aumento no número de PRs e commits, mas redução nos comentários.

### 2. Fichamento Bibliográfico

- **GitHub Actions:** Ferramenta introduzida pelo GitHub que permite a automação de tarefas com base em diversos gatilhos, como commits, pull requests e issues.

- **OSS:** OSS é a sigla para "Open Source Software", que em português significa "Software de Código Aberto".
